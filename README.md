# GrowthLane

Affiliate content site for the self-improvement / career-skills niche
(sales, leadership, mindset, communication). Built as a Jekyll site hosted
on GitHub Pages — publishing is just committing a new file to `_posts/`.

Networks: ClickBank, Digistore24 (Amazon Associates and CJ Affiliate to be
added later).

Live at: https://mikentg2005.github.io/growthlane/
